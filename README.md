# Digital Wallet Management System

A Java-based desktop application for digital wallet management, built using Java Swing, JDBC, MySQL, and a Java REST API backend.

## Features
- Login interface and dashboard
- Java Swing GUI
- MySQL database connectivity using JDBC
- Backend API for login, balance retrieval, and money transfer

## Technologies Used
- Java
- Java Swing and AWT
- JDBC
- MySQL
- Java HTTP Server

## Project Structure
- `WalletApp.java` — Main application and login interface
- `dashboard.java` — Dashboard interface
- `DBConnection.java` — Database connectivity
- `WalletBackend.java` — Backend API

## Setup
1. Install Java JDK and MySQL.
2. Create and configure the `digital_wallet` database.
3. Configure your database credentials securely.
4. Add the MySQL Connector/J driver.
5. Compile and run the Java files.

## Note
This is an academic project prototype. Configure database credentials locally before running it.
